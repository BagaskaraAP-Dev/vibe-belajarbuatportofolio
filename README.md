# ⚡ Bagaskara Dev — Vibe Coding & Portfolio

Proyek web modern yang memadukan profil mahasiswa Teknik Informatika Universitas Bina Darma Palembang dan mini-aplikasi interaktif **Vibe Coding Prompt Generator**.

## 📁 Struktur Folder Pre-Deployment

```text
vibe-portfolio/
├── index.html              # Entry point utama web
├── assets/                 # Aset statis
│   ├── images/             # Gambar & ilustrasi
│   └── icons/              # Ikon SVG
├── css/                    # Lembar gaya (styling)
│   └── style.css           # Styling modern (Glassmorphism & Responsif)
├── js/                     # Logika & interaktivitas
│   └── app.js              # Prompt generator engine & DOM interaction
├── .gitignore              # Menjaga file sensitif/lokal tidak ikut ter-upload
└── README.md               # Dokumentasi proyek
```

## 🚀 Cara Menjalankan di Lokal (Laptop)

### Opsi 1: Menggunakan Python Server bawaan Linux
Jalankan perintah ini di dalam folder proyek:
```bash
python3 -m http.server 3000
```
Lalu buka browser di: `http://localhost:3000`

### Opsi 2: Menggunakan Live Server di VS Code
1. Buka folder ini di VS Code (`code .`).
2. Klik kanan file `index.html`.
3. Pilih **"Open with Live Server"**.
